## 🔍 Token Types
- **Keyword** → int, float, char, double
- **Identifier** → variable names and general words
- **Operator** → +, -, *, /, =
- **Number** → numeric values (10, 20)
- **Symbol** → ; ( ) { }

## ⚙️ Implementation Details
- Language: **C++**
- Used manual scanning method (character-by-character parsing)
- Used functions to classify each token type
- Stored tokens dynamically using vectors

## 📤 Output
Each token is displayed along with its corresponding type in a tabular format.

## ▶️ How to Run

1. Compile the program :- g++ tokenizer.cpp -o tokenizer .
2. Run the program.
